# Novel Reader

Obsidian 沉浸式小说阅读插件。**移动端优先**，桌面端同样完整可用。

针对小说场景设计：横向翻页而非上下滚动、按章按需渲染、进度不惧重排、文件夹与单文件两种书籍形态都支持。

## 特性

**阅读**

- 横向分页：CSS 多列引擎 + 列宽精确对齐，像纸质书一样左右翻页
- 改稿自动刷新：正在读的文件被改动后自动重排版并保持位置（边写边看）
- 进度可视：`第 N/M 章 · a/b 页 · 全书 x%`
- 两种书籍形态：单文件大书（按标题自动切虚拟章）与文件夹分章（默认整文件夹都算，可手动排除设定稿）
- 网文爬站体：整篇缩进、一个 Markdown 标题都没有的文本，按「第 N 章」识别章节并直接按行渲染
- **书架视图**：侧边栏书架图标 / 命令面板 `打开书架` 打开一个常驻书架页，和阅读器平级
- 两种形态：网格卡片（书名首字生成封面色块）与列表，一键切换并记住选择
- 分类标签：全部 / 在读 / 收藏 / 未读 / 读完，标签上直接带计数
- 看到读到哪：每本书显示进度条、`已读 x%`、`读到 第四章 雨夜`、书签数与相对时间
- 置顶与显示名：常用的书置顶到最前，文件名不好看可以起一个只在书架里生效的别名
- 书籍详情：点 ⓘ 看进度、章节位置、书签数、路径（点击复制），置顶 / 改名 / 重置进度都在这里
- 批量操作：点「批量」进入多选，一次收藏、取消收藏或移除多本书
- **进度迁移**：单文件拆成文件夹（或合回单文件）后，详情里「迁移进度到…」把进度、书签、收藏一起搬过去，
  按章号匹配优先、百分比兜底，不用从头找读到哪
- **从书架隐藏**：误开的设定稿、单章文件可以从书架隐藏（进度保留），设置里随时恢复
- 显式收藏：没读过的书也能先收藏上架（书架或书库浏览里的 ★），收藏会跟着文件改名走
- 改名不丢进度：重命名书籍文件或文件夹后，进度与书签自动跟随

**交互**

- 点击分区：左右两侧翻页，中间唤出操作栏
- 移动端：滑动翻页、双指捏合缩放字号
- 桌面端：触控板横滑、方向键 / PageUp、PageDown / 空格
- 沉浸模式：隐藏标题栏与移动端导航栏

**外观**

- 字号 12–30px、行距 1.4–2.6 实时调节，改完自动回到原位
- 主题：跟随 Obsidian / 米色护眼 / 暗黑
- 每本书独立排版：这本调好的字号主题不会被另一本带走，也可在设置里一键恢复默认

**进度与检索**

- 三重冗余进度：章节序号 + 段落锚点 + 页内比例，重排后不错位
- 书签：当前位置打点 / 撤销，自动摘取段落摘要
- 书内搜索：全文子串匹配，直达命中的第一个段落；索引边读边建，弹窗不用等
- 目录：按标题或章节跳转，自动高亮并滚动到当前章

**设置**

安装后在 `设置 → 第三方插件 → Novel Reader` 里可调：字号 / 行距 / 主题、每本书独立排版、
沉浸模式、是否递归浏览书库、书架默认视图（网格 / 列表），以及清理失效记录、清除所有书的排版记忆。

## 安装

通过 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 安装：BRAT 设置 → Add Beta plugin → 填 `imluyg/obsidian-novel-reader`。

## 使用

- 侧边栏书本图标打开阅读器，会自动续读上次那本书；侧边栏书架图标打开书架
- 阅读中**点屏幕中间**唤出操作栏：书架、目录、书签、搜索、排版调节、主题、沉浸开关
- 书架里点书即开始阅读；点封面上的 ★ 收藏、ⓘ 看详情，点「批量」可多选操作
- 文件夹形态的书默认把文件夹里所有 md 都算作章节（0 字节的占位文件会跳过）；
  想排除设定稿、世界观这类非章节文件，就在书籍详情里点「重新选择章节」，选一次会记住
- 命令面板：`打开阅读器` / `打开书架` / `选择书籍` / `把当前书籍加入/移出书架` / `调试：切换移动端模拟`
- 更细的设置（含每本书独立排版、递归浏览开关）在插件设置页里

## 开发

```bash
build.bat   # 编译 TS 并部署 main.js（单文件构建）
```

- 目标：`isDesktopOnly: false`，桌面与移动端共用一套代码
- 红线：不依赖 Node/Electron API；正则不使用后行断言（兼容 iOS 16.4 以下 WebView）
- 分页交给 CSS multi-column，不在 JavaScript 里计算行高

## 已知限制

- 章节之间必定断页（不跨章节连续排版），与主流阅读器行为一致
- 文件夹形态的书：搜索索引在后台逐章建立，刚打开的那几秒可能还没覆盖到靠后的章节
  （单文件书直接在整本缓存里匹配，没有这个延迟）
- 目录弹窗一次渲染 300 条，更长的书点「显示更多」继续加载
- 进度数据存在 `data.json`，跨设备同步依赖支持插件数据同步的方案
- 迁移进度只能保到「章」：单文件与文件夹的段落划分不同，读到某一行的精确度保不住（章内位置按原比例估算）
- 0 字节的占位 md 会被自动跳过，不会产生空白页
